Initialization

python manage.py migrate
python manage.py prepare_locations
python manage.py load_fuel_prices --csv data/fuel-prices-for-be-assessment.csv

The supplied CSV must be present. City locations are loaded locally; full address geocoding requires explicit configuration and a contactable User-Agent. See README for the Nominatim policy.

Cost and coordinate interpretation

The optimizer uses a directed acyclic graph. Each feasible outgoing leg is priced at its source station. The first leg is valued using a departure inventory price proxy from the cheapest located imported station within 20 miles of departure. Leg cost includes the first and final legs. Purchases, leftover fuel and actual road detours are not simulated. Station locations are approximate Census place internal points, not verified pump locations.

Errors

400 invalid input/non-US location; 404 unresolved location/no driving route; 422 no departure price or infeasible refueling; 429 request limit; 502 invalid upstream response; 503 missing dataset, busy provider or timeout. JSON envelope: {"error":{"code":"...","message":"...","details":{},"request_id":"..."}}.
